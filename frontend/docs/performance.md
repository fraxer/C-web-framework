# Сравнение производительности

JSON: обновлён 2026-10-04. Один рабочий процесс приложения и восемь потоков выполнения.

Замеры базы данных: [PostgreSQL — выборка 20 строк из 1 000 000 записей](#postgresql-benchmark).
PostgreSQL и статика используют отдельные конфигурации, описанные в соответствующих разделах.

## Обработка JSON

### Серия девяти фреймворков — 2026-10-03, cwfr обновлён 2026-10-04

Обработчик POST `/count` получает ровно **1 048 576 байт (1 МиБ)** UTF-8 JSON, полностью разбирает документ и возвращает `{"count":4097}`. В объекте есть вложенные объекты/массивы, Unicode, экранированные строки и разные типы значений. Считаются ключи первого уровня; результат и дерево JSON между запросами не кешируются.

### Характеристики ПК

Intel Core i7-12700F, Linux host network.

Приложения и nginx:
* CPU 0–7 (четыре физических P-ядра с SMT),
* 2 ГиБ на контейнер приложения
* nofile 65536

wrk:
* восемь потоков на CPU 8–15

Общий nginx имеет два воркера и один upstream-адрес на приложение, ограничивает тело 2 МиБ, не буферизует тело и не кеширует ответы.\
TLS, сжатие, access log и БД отключены.

cwfr держит тело запроса в памяти.\
Rails — ActionController::Metal.\
Laravel использует разобранный JSON запроса и проход json_validate.\
facil.io применяет native FIOBJ JSON;\
Kore держит запроса тело в памяти и полностью строит дерево Jansson в фоновой задаче.

**90 замеров в одной серии:** девять фреймворков, два уровня конкурентности и пять повторов.

Всё сравнение повторено со сбором RSS: первичный прогрев 30 с, перед каждым замером 5 с, пять повторов по 15 с при 16/64 keep-alive соединениях, порядок перемешан с seed 20261003.

## PostgreSQL: выборка raw SQL {#postgresql-benchmark}

Дата серии: 2026-10-04.

Ядро CWFR: `5da69b013eec43a06f9cb61f4e2c681fadeb3f9e`. `main.body_store`: `mode: "auto"`, `file_threshold: 5000000` байт. Маленькое тело POST остаётся в памяти; лимит тела — 2097152 байт.

Запрос POST `/db` принимает `{"category":42,"after":1000}` и возвращает двадцать упорядоченных строк с полями id, category, name, price_cents и active.\
Отдельный PostgreSQL 17.6 содержит **1 000 000 синтетических записей**, составной B-tree индекс по `(category, id)`.\
Оба значения передаются через bind-параметры драйвера. ORM, кеш ответа приложения, TLS и PgBouncer не используются.\
Исполнение SQL, чтение всех двадцати строк, преобразование типов и сериализация JSON входят в измерение.

```sql
SELECT id, category, name, price_cents, active
FROM bench_items
WHERE category = $1::integer AND id > $2::integer
ORDER BY id
LIMIT 20;
```

Запрос и набор выбираемых полей эквивалентны во всех приложениях.\
Синтаксис placeholder адаптирован к драйверу.\
Восемь потоков клиента используют восемь разных фиксированных пар параметров с диапазонами по всей таблице, одна пара на поток.\
Каждый ответ сравнивается с полным ожидаемым документом из двадцати строк для этого потока.\
Пустая выборка и неверные параметры проверены на прямом порту приложения и через прокси.
